# 📊 Censo Estudiantil UNSL 2021 — Virtualidad y Pandemia

> **Universidad Nacional de San Luis (UNSL)**  
> Fecha del censo: 4 de octubre de 2021  
> Contexto: Segundo año de pandemia COVID-19 — Educación Virtual

---

## 🎯 Descripción

Análisis completo de las **10.913 respuestas** del censo estudiantil de la UNSL (octubre 2021). Relevó infraestructura tecnológica, experiencia de cursada virtual, dificultades y perspectivas post-pandemia.

**Dashboard online →** `https://msaitua.github.io/Censo-UNSL-2021/`

## 📊 Hallazgos Principales

| Indicador | Valor |
|-----------|-------|
| Total de respuestas | 10.913 |
| Residen en la ciudad de cursada | 80.4% |
| No trabajan | 60.5% |
| Dispositivo principal: notebook | 46.6% |
| Dispositivo principal: celular | 39.6% |
| Internet por proveedor | 70.9% |
| Sin conflictos por dispositivos | 45.9% |
| Evaluación Buena o Muy Buena | 50.7% |
| Prefiere modalidad bimodal | 70.5% |
| Gestión UNSL positiva | 70.0% |

---

## 📅 Comparación 2020 vs 2021

| Aspecto | 2020 | 2021 |
|---------|------|------|
| Total respuestas | 10.314 | 10.913 |
| Residen en SL | 88.0% | 80.4% |
| Dispositivo principal | Celular (76.7%) | Notebook (46.6%) |
| Eval. positiva general | 48.5% | 50.7% |
| Prefiere bimodal | 63.5% | 70.5% |
| Gestión UNSL positiva | 74.8% | 70.0% |

---

## 🔮 Perspectivas Post Pandemia

- **70.5%** prefiere modalidad bimodal
- **86.4%** de los que prefieren bimodal: al menos 1 presencial por semana
- **71.9%** cree que la UNSL debería continuar con educación virtual
- Solo **8.9%** preferiría virtualidad completa
